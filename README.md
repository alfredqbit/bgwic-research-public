# BGWIC Research

This repository is the public-facing project home for BGWIC research.

The implementation and source code remain private in the companion repository:

- https://github.com/alfredqbit/bgwic-research

This public repository is intended for:

- project overview and context
- issue tracking
- discussion and feedback
- research notes and public documentation
- roadmap and progress updates

## Status

This project is in active research and development. Public updates are intentionally limited to non-sensitive material.
